# EasyStudyAI

A source-grounded, interactive medical-school study assistant powered by your existing Codex/ChatGPT subscription. No OpenAI Platform API key or separate paid model API required.

**Status:** early development. Core learning skills, lecture import, and optional Pi integration are being added. Medical content is for learning, not clinical decisions.

Inspired by the workflow of [amosblomqvist/learn](https://github.com/amosblomqvist/learn), without bundling its source code.
